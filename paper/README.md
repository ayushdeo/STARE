# paper/ — arXiv-ready manuscript (NeurIPS style)

Source for *Adaptivity Without Reward: A Negative Result for Closed-Loop Region Acquisition in Spatial
Transcriptomics*, formatted with the NeurIPS style in **preprint** mode (author names shown, no line
numbers, no "Submitted to…" banner) — ready for arXiv.

## Files (all four go in the arXiv tarball)
- `manuscript.tex` — the paper (§1–§8 + Appendix A).
- `references.bib` — bibliography; authors/venues/DOIs verified against primary sources (2026-09).
  AFA-RL is cited as an arXiv preprint (venue unconfirmed); GenAR/ReconST carry journal + arXiv/bioRxiv id.
- `neurips_2023.sty` — the NeurIPS style file (arXiv has no TeX-Live copy, so it must be bundled).
- `figure1_adaptivity_gap.pdf` — Figure 1, generated by `../scripts/06_plot_figure1.py` from the CI
  result JSONs. Regenerate with that script; do not hand-edit.

## Compile
Numeric citations (natbib `[numbers]`), `plainnat`. Standard four-pass build:
```bash
pdflatex manuscript
bibtex   manuscript
pdflatex manuscript
pdflatex manuscript
```
Easiest path: upload the four files above to **Overleaf** (or import the repo) and hit Recompile.

## Build the arXiv submission tarball
arXiv runs bibtex itself, **but** the robust practice is to include the compiled `manuscript.bbl` so the
build never depends on bibtex resolving. Do one clean local/Overleaf compile, grab `manuscript.bbl` from
the output, then:
```bash
# from paper/ , after a successful compile that produced manuscript.bbl
tar czf arxiv_submission.tar.gz manuscript.tex manuscript.bbl neurips_2023.sty figure1_adaptivity_gap.pdf
```
Upload `arxiv_submission.tar.gz` at arxiv.org/submit. (If you omit the `.bbl`, also include
`references.bib` and let arXiv run bibtex.) Primary category suggestion: **cs.LG**, cross-list
**q-bio.GN** and **q-bio.QM**.
