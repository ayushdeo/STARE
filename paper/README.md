# paper/ — compilable manuscript

Self-contained LaTeX source for *Adaptivity Without Reward: A Negative Result for Closed-Loop Region
Acquisition in Spatial Transcriptomics*.

## Files
- `manuscript.tex` — the paper (Intro → Conclusion, §1–§8).
- `references.bib` — bibliography; author lists, venues, and DOIs verified against primary sources
  (2026-09). AFA-RL is cited as an arXiv preprint (venue unconfirmed); GenAR/ReconST carry both the
  journal and the arXiv/bioRxiv identifier.
- `figure1_adaptivity_gap.pdf` — Figure 1, generated by `scripts/06_plot_figure1.py` from the CI
  result JSONs (regenerate with that script; do not hand-edit).

## Compile
Locally (needs a TeX distribution) or on Overleaf / the arXiv build:
```bash
pdflatex manuscript
bibtex manuscript
pdflatex manuscript
pdflatex manuscript
```
`docs/MANUSCRIPT.md` is the Markdown source of record for prose; keep the two in sync when editing.
Numbers come from `results/ci_multislide_*.json` via `scripts/04_make_results_table.py` — never retype.
